スマホのホーム画面に追加してアプリ化する方法

ステップ1：無料URLで公開する（所要1分・初回のみ）
iPhone（Safari）はローカルファイルのままだとホーム画面に追加できないため、配布した strategy_trainer_pwa.zip を Netlify Drop（app.netlify.com/drop）または GitHub Pages にアップロードして自分の専用URL（https://〜）を発行します。
ステップ2（iPhone / Safari）
  1. 発行した自分の専用URLを Safari で開く
  2. 画面下部の 共有ボタン（□に↑） をタップ
  3. 「ホーム画面に追加」 → 右上の「追加」をタップ
ステップ2（Android / Chrome）
  1. 発行した自分の専用URLを Chrome で開く
  2. 右上の ︙（メニュー） をタップ
  3. 「ホーム画面に追加」 または 「アプリをインストール」 をタップ

※一度ホーム画面に追加して開けば、オフライン環境（通学中・地下鉄等）でも動作し、追加した問題やSRS学習履歴はすべてスマホ内に保存されます。
